# Vídeos do Nielle Fit

Esta pasta contém os vídeos próprios/licenciados usados pelo player HTML5 nativo do Nielle Fit.

Formato recomendado: MP4 (H.264 + AAC), orientação horizontal 16:9, áudio em português, resolução 720p ou 1080p.

Arquivos esperados:

## Treino A
- puxada-frente.mp4
- supino-maquina.mp4
- remada-baixa.mp4
- elevacao-lateral.mp4
- prancha.mp4

## Treino B
- leg-press-45.mp4
- cadeira-extensora.mp4
- cadeira-flexora.mp4
- abducao-quadril.mp4
- panturrilha-em-pe.mp4

## Treino C
- agachamento-smith.mp4
- desenvolvimento.mp4
- puxada-triangulo.mp4
- gluteo-maquina.mp4
- abdominal.mp4

O index.html usa `<video controls playsinline preload="metadata">` e caminhos relativos desta pasta. Assim que os MP4 forem adicionados com estes nomes, os players passam a reproduzi-los automaticamente sem iframe/YouTube.
